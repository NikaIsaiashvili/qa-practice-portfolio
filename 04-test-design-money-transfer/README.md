# Test Design: Money Transfer Form

[← Back to portfolio](../README.md)

**Status:** Not started · **Type:** Independent practice (test design only)

This project is **test design, not test execution**. There is no application. The input is a short written [specification](specification.md) for a fictional money transfer form, and the output is a set of test cases designed from it.

## Deliverables

- [ ] `test-cases.md`: test cases that cover every rule in the specification, using the [test case template](../templates/test-case-template.md). Leave **Actual result** empty and set **Status** to "Not run".
- [ ] Equivalence partitions and boundary values for the amount field
- [ ] A decision table for the fee rules
- [ ] A state transition table for the transfer statuses
- [ ] `questions.md`: unclear or missing points in the specification, written as questions for the product owner

Update the status line above when work starts and when it is complete.
